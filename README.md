# Tiểu luận Quản lý Nhà hàng (Cấu trúc dữ liệu & Giải thuật)

## 1. Giới thiệu dự án
Hệ thống quản lý nhà hàng viết bằng ngôn ngữ C, sử dụng Danh sách liên kết đơn để quản lý thực đơn và hóa đơn bàn ăn.

## 2. Cấu trúc thư mục
- `include/`: Chứa các file khai báo `.h`
- `src/`: Chứa các file mã nguồn `.c`
- `data/`: Chứa file lưu trữ dữ liệu `.txt`

## 3. Phân công nhiệm vụ
- Khởi tạo, nhập & xuất: Nguyễn Tài Năng
- Tìm kiếm, sắp xếp, cập nhật, xóa: Lữ Thành Tài
- Đọc & ghi file, quản lý bàn ăn: Trần Phạm Vinh Quang
